# 구현 및 미완료 항목

| 단계 | 구현한 기능 | 남은 검증·제약 |
|---|---|---|
| 1. 작업 공간 | 한국어 7개 화면, 밝게·어둡게, 반응형 화면, 지표 출처·동기화·기간 필터, 편집 보드·수정 이력·자료 승인·수동 제작 시간, 실제 작업 기반 입체 오피스 | 단계 이동은 접근 가능한 버튼을 사용합니다. 직원 활동을 추정하지 않습니다. |
| 2. 정보 수집 | RSS 및 직접 출처 등록, 이용 권한·날짜·중복 관리, 설명 가능한 관련도, 불확실한 주장 표시, 저장·제외·프로젝트 생성, 선택적 출처 기반 AI 초안·제안 | OpenAI 실제 계정 종단 검증, 허가된 뉴스 API·Google Trends·경쟁 채널 어댑터는 추가 작업이 필요합니다. 피드 제목 조회를 사실 검증 완료로 간주하지 않습니다. |
| 3. Canva | 정확한 원본 3개, 실제 미리보기·디자인 데이터셋 검사, 원본 기반 새 디자인 생성, 승인된 사본 브랜드 템플릿 설정, 문구·이미지·영상 필드, 결과 확인·편집 링크, 수동 사본 등록, 페이지별 PNG·릴스 MP4 내보내기 | 실제 계정 인증 후 이용 자격 및 원본 필드 확인이 필요합니다. 픽셀 단위 일치·줄바꿈은 사람이 검토합니다. 페이지 수 변경은 승인된 해당 수의 사본을 준비합니다. 직접 파일 업로드 UI는 미구현이며 미디어 필드는 기존 Canva 자료 ID를 사용합니다. |
| 4. Instagram 지표 | @themovemag_ 자동 발견·이름 및 ID 확인, 게시 전 계정 재확인, 공식 Graph 계정·게시물 기록, 미제공 지표 빈 값, 규모를 고려한 분석 | 실제 Meta 권한·앱 검토 및 계정 종단 검증이 필요합니다. 매 실행의 최근 게시물 수집은 제한되어 있으며 전체 과거 기록 가져오기는 별도입니다. |
| 5. 게시 및 학습 | 현재 버전 편집 승인, 최종 미디어·순서·캡션 게시 승인, 캐러셀 자식·부모 컨테이너와 릴스 게시, 실제 게시물 ID 확인, 반복·불명확한 요청 차단, Redis 재시도·작업 이력·정기 처리, 사람이 승인하는 개선 실험 | 실제 계정 생성·게시 검증은 인증이 없어 미완료입니다. 불명확한 제공자 요청 결과 대조는 관리자가 수행하며 자동 재게시하지 않습니다. 영구 미디어 저장소 업로드는 미구현입니다. |

API 응답을 대체한 테스트는 계약 및 상태 처리 검증입니다. 외부 서비스의 실제 계정 테스트 통과를 의미하지 않습니다. 데모에서는 실제 Instagram 게시가 차단됩니다. 정확한 계정은 @themovemag_이며 다른 브랜드의 편집 데이터는 유지하되 실제 연동은 현재 차단합니다.
