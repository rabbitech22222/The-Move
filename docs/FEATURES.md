API 응답을 대체한 테스트는 계약 및 상태 처리 검증입니다. 외부 서비스의 실제 계정 테스트 통과를 의미하지 않습니다. 데모에서는 실제 Instagram 게시가 차단됩니다. 정확한 계정은 @themovemag\_이며 다른 브랜드의 운영 데이터와 추가 채널 UI·API를 제거합니다.

기본 실행은 LOCAL_MODE=true, DEMO_MODE=false입니다. 파일 운영은 실제 작업을 `.move-local`에 보관하고 단일 로컬 처리기가 뉴스·생성·예약 작업을 처리합니다. 일반 PostgreSQL 운영의 Prisma와 BullMQ/Redis 경로는 유지합니다. 자동 데이터 이전, 영구 파일 업로드, 실제 외부 계정 인증 없는 생성·게시 검증은 제공하지 않습니다.
