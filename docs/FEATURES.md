Security: signed HttpOnly expiring sessions, password scrypt hashes, two operator accounts, role checks, same-origin mutation protection, secret metadata only in UI, AES-256-GCM stored OAuth tokens, state/PKCE for Canva, significant changes audited. This is a single-workspace application with workspace-scoped tables, not complete multi-tenant SaaS isolation. Production still needs deployment controls, backups, monitoring, independent security review, and provider app review appropriate to the chosen deployment.

Demo fixtures are explicitly synthetic; example.com topic URLs are fixture references, not verified reporting sources. Production seeding creates disconnected accounts/templates and **no metrics, posts, topics, employee activity, publishing successes, or fake approvals**.
